## Voice, type and software

- Narration: Kokoro-82M by hexgrad (Apache-2.0), voice `bm_fable`, British English, speed 0.92, run with kokoro-onnx (MIT). A synthetic voice; it imitates no real person.
- Sound: room tone and cues are generated by code (`engine/sound.py`). No samples or music.
- Type: Inter and Inter Display, Copyright (c) 2016 The Inter Project Authors (SIL Open Font License 1.1); JetBrains Mono, Copyright 2020 The JetBrains Mono Project Authors (SIL Open Font License 1.1).
- Picture: drawn with Pillow; encoded with PyAV (FFmpeg, libx264).
- Design reference: Lemo-Opuscar by Lemomo (LemoLab), https://github.com/lemomo-ai/lemo-opuscar . Its style documents (CC BY-NC 4.0) were read as a reference; no text, code, assets or colours from it are used.
